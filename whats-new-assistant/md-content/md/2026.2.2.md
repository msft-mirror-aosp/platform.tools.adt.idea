# What's New in Rabbit 2

**[Read in a browser ↗](https://d.android.com/r/studio-ui/whats-new-assistant/preview-release-notes/2026-2-2)**

![Rabbit 2 icon](https://developer.android.com/static/studio/images/splash-screens/rabbit-2.png)

This panel describes some of the new features and behavior changes
included in this update.

To open this panel again later, select **Help > What's New in Android Studio**
from the main menu.

## Bring Your Own Agent (BYOA): Integrate your preferred coding agents

![Select an AI agent in the Agent tool window](https://developer.android.com/studio/releases/assistant/images/byoa.png)

Building on Android Studio's support for custom AI models, Android Studio
Rabbit 2 Canary 1 introduces Bring Your Own Agent (BYOA). Using BYOA, you can
connect your preferred AI coding agents—including Claude Agent, OpenAI Codex,
and Google Antigravity—directly into Android Studio using the open Agent Client
Protocol (ACP). To get started, select an agent in the agent window and sign in
or provide an API key, or find additional agents at **File** (**Android
Studio** on macOS) **> Settings > Tools > AI > Agents**.

[Learn more ↗](https://d.android.com/r/studio-ui/ai/byoa)

## Compose Preview Screenshot Testing tool

![Test Compose UIs with the screenshot testing tool](https://developer.android.com/studio/releases/assistant/images/compose-screenshot-testing.png)

Use the Compose Preview Screenshot Testing tool to test your Compose UIs and
mitigate regressions. The new tool helps you generate HTML reports that let you
visually detect any changes to your app's UI.

[Learn more ↗](https://d.android.com/r/studio-ui/debug/compose-screenshot)

## Model Assignment

![Model Assignment
setting](https://developer.android.com/studio/releases/assistant/images/model-assignment-wna.png)

The Model Assignment feature lets you pick different AI models for different
types of tasks in Android Studio. To configure this, go to **File** (**Android
Studio** on macOS) **> Settings > Tools > AI > Model Providers**, select the
**Model Assignment** tab, and use the dropdowns to assign a model for each
feature category.

[Learn more ↗](https://d.android.com/r/studio-ui/ai/model-assignment)

## Migrate iOS, Flutter, and React Native apps to Android

![Migrate apps to
Android](https://developer.android.com/studio/releases/assistant/images/migrate-ios-apps.png)

You can now migrate existing iOS, Flutter, and React Native projects to native
Android using automated migration tooling in Android Studio. From the New
Project Wizard, you can call the assistant to convert the selected project to a
Kotlin and Jetpack Compose-based Android app. The integrated progress UI
provides end-to-end visibility across task planning, code transformation, and
compilation checks, producing a functional project that's ready for testing and
verification.

[Learn more ↗](https://d.android.com/r/studio-ui/design/migrate-ios)

## Resize Running Devices tool window by double-clicking empty space

You can now quickly eliminate unused space around your virtual or mirrored
physical devices in the **Running Devices** tool window. Simply **double-click
anywhere in the empty background area** outside the device screen (and frame, if
visible) to automatically resize the tool window or adjust split pane
proportions to snugly fit the device display.

* **Docked tool windows:** Adjusts the tool window's width (when docked to the
  left or right) or height (when docked to the top or bottom) to remove excess
  margin around the device.
* **Floating and windowed modes:** Resizes both width and height of the window
  to wrap tightly around the device display.
* **Split views:** Automatically adjusts internal splitters when viewing
  multiple displays or devices side by side.

## Studio Labs features available

![Studio Labs in settings](https://developer.android.com/studio/releases/assistant/images/studio-labs.webp)

Studio Labs lets you try out the latest AI experimental features in a stable

default in canary versions of Android Studio.
